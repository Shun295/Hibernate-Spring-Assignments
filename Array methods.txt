JavaScript Array Methods - Quick Cheat Sheet
Method	Purpose	Returns
map()	Transform each element	New array
filter()	Select matching elements	New array
find()	Get first matching element	Object/value or undefined
reduce()	Combine array into a single value	Single value
sort()	Arrange elements in order	Sorted array
Simple Examples
// map() - modify each item
employees.map(e => e.name);

➡️ Get all names

// filter() - get matching items
employees.filter(e => e.department === "IT");

➡️ Get all IT employees

// find() - get first match
employees.find(e => e.id === 3);

➡️ Get employee with id 3

// reduce() - accumulate values
employees.reduce((sum, e) => sum + e.salary, 0);

➡️ Total salary

// sort() - arrange data
employees.sort((a, b) => a.salary - b.salary);

➡️ Sort by salary ascending

Common Combinations
filter() + map()

➡️ Filter data, then extract specific fields

Example:

employees
    .filter(e => e.department === "HR")
    .map(e => e.id);

Get IDs of HR employees.

filter() + reduce()

➡️ Filter data, then calculate

Example:

employees
    .filter(e => e.department === "IT")
    .reduce((sum, e) => sum + e.salary, 0);

Total IT salary.

filter() + sort()

➡️ Filter data, then order it

Example:

employees
    .filter(e => e.department === "IT")
    .sort((a, b) => a.salary - b.salary);
